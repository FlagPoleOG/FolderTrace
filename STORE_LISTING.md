## Description

AppData fills up with folders from programs and games you uninstalled years ago, often under names that make no sense. FolderTrace tells you which program each folder belongs to, how sure it is, and why.

It looks at what's installed, your game libraries, shortcuts, Windows' record of programs you've run, and small log and settings files, then labels every folder:

In use: the program is still on your PC.
Likely leftover: nothing on your PC uses it anymore.
Not sure: FolderTrace can't tell, so it says so instead of guessing.
Windows or shared: Windows folders and caches that you shouldn't touch. These can't be selected for removal.

Every label comes with the evidence behind it, so you can decide for yourself. FolderTrace warns you when a folder may hold game saves or sign-ins, and checks Program Files too.

When you're ready, check the leftovers and choose Delete checked. Folders go to the Recycle Bin, so you can put them back. Scanning never changes anything.

FolderTrace is a small native Windows app. It runs entirely on your PC, never connects to the internet, and has no account, ads, or tracking.

Made by Second Shift Software.

## Product features

- Shows which program each AppData and Program Files folder belongs to
- Labels folders In use, Likely leftover, Not sure, or Windows or shared
- Explains the evidence behind every label
- Warns about folders that may hold game saves or sign-ins
- Recognizes game folders by their code names using your Steam library
- Moves checked folders to the Recycle Bin, never deletes permanently
- Mark labels Right or Wrong to keep track of what it got right
- Save the full list as a CSV report
- Runs offline, with no account, ads, or tracking
